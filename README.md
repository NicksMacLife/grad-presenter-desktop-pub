# GradPresenter desktop — releases

This repository only publishes builds of the GradPresenter desktop app (presentation machines and queue stations). Source code is kept privately.

**Download the latest version**

- Windows: [GradPresenter-Setup.exe](https://github.com/NicksMacLife/grad-presenter-desktop-pub/releases/latest/download/GradPresenter-Setup.exe)
- macOS: [GradPresenter-mac.dmg](https://github.com/NicksMacLife/grad-presenter-desktop-pub/releases/latest/download/GradPresenter-mac.dmg)

These links always point to the newest release. Signed-in customers can also download from **Desktop app** in the GradPresenter portal. Installed apps update themselves automatically from this repository's releases. They never restart during a ceremony.

A GradPresenter organization account is required to use the app.

Release files are uploaded by an automated build workflow. Please do not upload or edit release assets by hand.
